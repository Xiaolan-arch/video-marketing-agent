# 视频营销智能体（Video Marketing Agent）
> 基于 Python + Streamlit 构建的AI营销内容决策工具，面向短视频营销场景，实现素材优化、文案生成、图片风格转换与配额激活管理一体化网页应用。

## ✨ 项目简介
本项目为本地Demo级别的AI营销智能体，通过大模型接口完成营销素材决策、图片优化、风格换图等能力；内置激活码配额机制，控制用户调用次数，适合作为AI营销工具原型进行二次开发与功能迭代。

- 网页前端：Streamlit，开箱即用，无需复杂前端部署
- 核心能力：营销素材决策、Prompt自动构建、图片优化生成、结果持久化保存
- 业务机制：激活码次数配额，使用记录本地持久化（quota.json）
- 开发语言：Python 3.11

## 🚀 本地快速启动
### 1. 环境依赖安装
推荐 Python >=3.11
```bash
pip install streamlit
```

> 
> 如后续运行提示缺少其他模块，使用 `pip install 模块名` 安装。

### 2. 启动项目

进入项目根目录，终端执行：

```
streamlit run app.py
```

启动成功后，浏览器自动打开：`http://localhost:8501`

## 📌 使用说明

1. 打开网页，在侧边栏输入激活码，点击【激活】解锁调用次数；
2. 支持图片上传，执行素材优化、风格替换等任务；
3. 每次调用消耗对应配额，使用记录自动保存至 `quota.json`；
4. 生成的结果会自动保存到【输出】文件夹。

> 
> 注意：当前为本地 Demo 版本，配额逻辑写死在本地代码。生产部署建议将配额迁移至后端服务，做数据库持久化。

## ⚙️ 项目特性

- 可视化 Web 界面，低门槛操作，无需懂代码即可使用
- Prompt 工程封装，自动构建 AI 任务指令
- 模型返回结果自动解析，结构化输出
- 本地文件持久化，保存激活码记录与生成结果
- 支持图片上传与媒体素材处理
